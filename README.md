# Yt-emb
Chrome extension used to embed blocked YouTube videos through script injection

# Installation
Download in [Chrome Web Store](https://chromewebstore.google.com/detail/yt-emb-quick-simple-youtu/bjlecdganfgddbcnnmioaingpljikoni)

# Usage
Two commands:
- **Ctrl+Shift+Up** replaces the blocked Youtube message with an embedded iframe element
- **Ctrl+Shift+Down** opens a new tab as a "nocookie" video, an embedded video without ads

# Other Stuff
I think you can bypass Youtube ads in general by embedding a video, so what this chrome extension does is replace the old youtube video with an iframe of it, meaning the video is embedded
